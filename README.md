# Interactive Calculator & Unit Converter

A simple Python command-line calculator for everyday arithmetic and a few common unit conversions. This is my InternCircle Project 01.

## What it can do

- Add, subtract, multiply and divide two numbers
- Convert kilometres to miles
- Convert Celsius to Fahrenheit
- Convert kilograms to pounds
- Keep showing the menu until the user chooses to quit
- Ask again when the user enters something that is not a number
- Handle division by zero with a message instead of a traceback

## Requirements

- Python 3.10 or newer
- No extra packages are needed

## Run it

Open a terminal in this folder and run:

```bash
python3 calculator.py
```

On Windows, you can use:

```bash
python calculator.py
```

## Run the tests

```bash
python3 -m unittest -v
```

## Project files

- `calculator.py` - the calculator and conversion menus
- `test_calculator.py` - tests for the arithmetic and conversion functions
